# WireGuard Configuration — Reference

This document provides sanitised reference configurations for the WireGuard VPN setup in this lab. Real private keys and public IP addresses have been replaced with placeholders.

| Interface Keys | Auto-generated by pfSense |

## Client Configuration File

Save as `wg0.conf` and import into the WireGuard client application.

```ini
[Interface]
# Client's private key — generated on client device, never shared
PrivateKey = <client_private_key>

# IP assigned to this client inside the VPN tunnel
Address = 192.168.2.2/24

# Use pfSense as DNS when connected (optional)
DNS = 192.168.1.1

[Peer]
# pfSense server's public key
PublicKey = <server_public_key>

# Home router's public IP and WireGuard port
Endpoint = <home_public_ip>:51820

# Traffic for lab networks routed through VPN (split tunnel)
AllowedIPs = 192.168.1.0/24, 192.168.2.0/24

# Keep tunnel alive through NAT (important for mobile connections)
PersistentKeepalive = 25
```

---

## Split Tunnel Explanation

`AllowedIPs = 192.168.1.0/24, 192.168.2.0/24` means:

- Only traffic destined for the lab network (`192.168.1.x`) and VPN subnet (`192.168.2.x`) travels through the encrypted tunnel
- All other internet traffic (YouTube, email, etc.) routes normally through the client's local internet connection
- This reduces VPN bandwidth load and prevents routing all internet traffic through the home connection

To route **all** traffic through the VPN (full tunnel), change to:
```ini
AllowedIPs = 0.0.0.0/0, ::/0
```

## Home Router Port Forward

Required to allow WireGuard connections to reach pfSense from the internet:

| Setting | Value |
|:---|:---|
| Protocol | UDP |
| External Port | 51820 |
| Internal IP | `192.168.100.x` (pfSense WAN IP) |
| Internal Port | 51820 |

## Verifying the Connection

On the client, after importing and activating the config:

```bash
# Check tunnel status
wg show

# Expected output includes:
# latest handshake: X seconds ago
# transfer: X MiB received, X MiB sent

# Verify lab network is reachable
ping 192.168.1.1

# Access pfSense GUI
# Browser: https://192.168.1.1
```
